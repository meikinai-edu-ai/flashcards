# Карточки для повторения

Сайт с флеш-карточками для курса «Анализ и визуализация данных» (Excel и Power BI).
Студенты открывают ссылку на телефоне или компьютере, выбирают тему и проверяют себя.
Прогресс каждого студента хранится в его браузере, регистрация не нужна.

## Как добавить новую тему

1. Подготовьте Excel-файл с карточками (лист «Карточки», те же колонки, что в первом файле).
2. Откройте папку `cards` в этом репозитории.
3. Нажмите **Add file → Upload files**, перетащите файл и нажмите **Commit changes**.
4. Через 1–2 минуты тема появится на сайте. Ход публикации виден на вкладке **Actions**.

Имена файлов пишите латиницей, без пробелов. Темы внутри модуля идут в порядке имён
файлов, поэтому удобно начинать имя с номера: `01-tipy-dannyh.xlsx`, `02-formuly.xlsx`.

## Как исправить карточку

Исправьте Excel-файл у себя и загрузите его в папку `cards` с тем же именем:
новая версия заменит старую.

## Как убрать тему

Откройте файл в папке `cards`, нажмите на значок корзины (Delete file) и **Commit changes**.

## Что где лежит

- `index.html` — сам сайт. Название курса и подзаголовок меняются в начале блока `CONFIG`.
- `cards/` — Excel-файлы с карточками, по одному на тему.
- `.github/workflows/deploy.yml` — автоматическая публикация сайта при каждом изменении.
